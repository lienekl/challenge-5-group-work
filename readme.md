# Group Project: Interactive Web Application using a 3rd Party API

This project was created as part of a Week 5 challenge to demonstrate our knowledge and skills in JavaScript and third-party API integration.

This was a group project focused on wireframing, designing, planning, and developing an interactive web application using HTML, CSS, and JavaScript, while utilising one or more third-party APIs.

# Key Features

* Implemented REST Countries API — https://restcountries.com and build a “World Explorer” app where users search for a country and see key details and its flag.

* Created a wireframe using draw.io to visualise layout, user flow, and functionality before development

* Designed and styled the web application using HTML and CSS

* Used JavaScript to fetch data from external APIs and add interactivity and dynamic content to the page

* Integrated the Google Maps API to display a small map showing the selected country’s location at the bottom of the page
